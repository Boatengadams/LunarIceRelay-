# Game Design Document — BAGS EXPLORE: Lunar Ice Relay

## Premise
Players design and operate a lunar south-pole ice investigation: rover + instruments + CubeSat relay.

## Modes
- **Single Player** — one seat, all roles stacked.
- **Local Co-op** — 1–4 players, role assignment/stacking.

## Roles
1. Mission Commander — timeline, resources, decisions  
2. Rover Operator — drive, navigate, collect  
3. Communications Engineer — CubeSat deploy/relay  
4. Mission Scientist — instruments, analysis  

## Destinations
- Moon — available  
- Mars — locked via game logic  

## Menu
START MISSION, HOW TO PLAY, ABOUT, SETTINGS, EXIT  

## Success (gameplay)
Collect required ice samples, complete science points, return data via CubeSat within mission timer.
